# Disclaimer

This repository is a public reference implementation for a low-stakes workshop planning scenario. It uses synthetic fixture documents and does not contain private, sensitive, regulated, or organization-specific data.

The workflow uses a reviewable document-to-structured-data pattern. It is not a production deployment, a complete document-processing platform, or a substitute for human review.

Generated outputs may include accepted facts, flagged conflicts, rejected unsupported claims, and unresolved questions. A human reviewer should resolve warnings before using the run sheet for real coordination.

Any live OpenAI execution depends on local environment variables and the reviewer's own provider access. The deterministic fallback path remains the reproducible checked-in proof.
